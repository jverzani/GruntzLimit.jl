# GruntzLimit

[![Build Status](https://github.com/jverzani/GruntzLimit.jl/actions/workflows/CI.yml/badge.svg?branch=main)](https://github.com/jverzani/GruntzLimit.jl/actions/workflows/CI.yml?query=branch%3Amain)


Implementation of the Gruntz algorithm from (D. Gruntz, "On Computing Limits in a Symbolic Manipulation System", 1996) for symbolic algebra systems in Julia using the `TermInterface`. Generated by Claude AI.


```julia
using GruntzLimit # export gruntz_limit, GruntzError
using SymEngine
@vars x a
gruntz_limit((1 + 1/x)^x, x, Inf)           # exp(1)
gruntz_limit((1 + a/x)^x, x, Inf)           # exp(a)
gruntz_limit((x^x - x^a)/(a^x - a^a), x, a) # 1
```



See also [SymbolicLimits](https://github.com/SciML/SymbolicLimits.jl).
