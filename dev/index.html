    GruntzLimit.jl#

    Limits of univariate real expressions using the algorithm of D. Gruntz, On Computing Limits in a Symbolic Manipulation System (PhD thesis, ETH Zürich, 1996).

    The package does not depend on a computer algebra system. Any symbolic term type that implements the TermInterface.jl methods iscall, operation and arguments can be used. These docs show three such types:

    • SymEngine.jl (Basic), a full symbolic library whose answers come back as exact Basic values;

    • SymbolicUtils.jl, the term library underlying Symbolics.jl;

    • Julia's own Expr, which needs no extra packages at all.

    SimpleExpressions.jl is also tested.

    The input is converted to an internal canonical form. All of the algorithm's work (finding the most rapidly varying subexpressions, rewriting, series expansion) is done there, and the answer is rebuilt in your term type by calling operations as functions.

    This package was implemented by Claude Code. See also SymbolicLimits.jl, which implements Gruntz's algorithm for Symbolics.jl. The comparison (the badge above) has both packages on 66 limit problems, the examples of Gruntz's thesis among them; see benchmark/limits/README.md in the repository to rerun it.

    Example#

    using GruntzLimit
using SymEngine: @vars
@vars x a

gruntz_limit((1 + a/x)^x, x, Inf)
    \[e^{a}\] 
    gruntz_limit((x^x - x^a)/(a^x - a^a), x, a)
    1

    The same limit with Expr input, with the variable and parameter given as Symbols:

    gruntz_limit(:((x^x - x^a)/(a^x - a^a)), :x, :a)
    1

    The only entry point is gruntz_limit. When a limit does not exist, or cannot be computed, it throws a GruntzError.
