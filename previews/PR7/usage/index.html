    Usage#

    gruntz_limit(f, x, x0 = Inf; dir = :+, build = nothing, lift = nothing)

    computes \(\lim_{x \to x_0} f(x)\). The limit point x0 may be Inf, -Inf, a number, or an expression that does not contain x. For a finite x0, dir chooses the side the limit is taken from: :+ (from the right, the default), :- (from the left), or :both (both one-sided limits are computed and must agree).

    Rational limits come back as Int or Rational, and infinite limits as Inf or -Inf, whatever the input type. Other answers, such as \(e\) or \(\pi/2\), are rebuilt in the input's term type.

    SymEngine#

    With SymEngine, create the variable (and any parameters) with @vars. Then write the expression as you normally would.

    using GruntzLimit
using SymEngine
@vars x a

gruntz_limit(sin(x)/x, x, 0)
    1

    Limits at infinity are the default:

    gruntz_limit(x^2 * exp(-x), x)
    0
    gruntz_limit(sqrt(x^2 + x) - x, x)
    1//2

    Answers that are not rational are returned as exact Basic values:

    gruntz_limit((1 + 1/x)^x, x)
    exp(1)
    gruntz_limit(atan(x), x, -Inf)
    (-1/2)*pi
    gruntz_limit((sin(x)/x)^(1/x^2), x, 0)
    exp(-1/6)

    Parameters can appear in the expression and in the limit point:

    gruntz_limit((1 + a/x)^x, x)
    exp(a)
    gruntz_limit((x^x - x^a)/(a^x - a^a), x, a)
    1

    One-sided limits:

    gruntz_limit(1/x, x, 0; dir = :-)
    -Inf
    gruntz_limit(sqrt(1 - cos(2x))/x, x, 0; dir = :-)
    -sqrt(2)

    Cancellation between exponentials, the kind of limit Gruntz's algorithm handles well:

    gruntz_limit(exp(x + exp(-x)) - exp(x), x)
    1
    gruntz_limit(1/x^2 - 1/sin(x)^2, x, 0)
    -1//3

    SymEngine's own infinity, oo, can be used as the limit point:

    gruntz_limit(x^x / exp(x), x, oo)
    Inf

    Julia Expr#

    TermInterface.jl defines iscall, operation and arguments for Julia's Expr, so a quoted expression works without any symbolic package. The variable is passed as a Symbol:

    using GruntzLimit

gruntz_limit(:(sin(x)/x), :x, 0)
    1
    gruntz_limit(:(1/x^2 - 1/sin(x)^2), :x, 0)
    -1//3
    gruntz_limit(:(x/abs(x)), :x, 0; dir = :-)
    -1

    A parameter is just another Symbol, and it can also be the limit point:

    gruntz_limit(:((x^x - x^a)/(a^x - a^a)), :x, :a)
    1

    Expr answers#

    For Expr input, a non-rational answer is returned as an unevaluated Expr, so it stays exact and may contain parameters:

    gruntz_limit(:((1 + 1/x)^x), :x)
    :(exp(1))
    gruntz_limit(:((1 + a/x)^x), :x)
    :(exp(a))
    gruntz_limit(:(sqrt(x^2 + a*x) - x), :x)
    :(1//2 * a)
    L = gruntz_limit(:(atan(1/x)), :x, 0; dir = :-)
    :(-1//2 * π)

    The result is an ordinary expression, so it can be evaluated:

    eval(L)
    -1.5707963267948966

    The answer is assembled by a build function, which receives an operation (a Julia Function such as +, *, ^, exp, log, sin, cos, atan, sqrt) and its arguments. For Expr input the default is (op, args...) -> Expr(:call, nameof(op), args...). Pass a different build to change this. For example, calling the operations evaluates constant answers to floating point:

    gruntz_limit(:((1 + 1/x)^x), :x; build = (op, args...) -> op(args...))
    2.718281828459045

    Supported functions#

    The operations understood are

    +, -, *, /, ^, inv, sqrt, cbrt, exp, log (one or two arguments), sin, cos, tan, atan, abs, sinh, cosh, tanh.

    Each operation can be given as a Julia Function or as its Symbol name. The named constants pi/π, E/ℯ, EulerGamma, Catalan and GoldenRatio are recognised. Anything else gives a GruntzError:

    try
    gruntz_limit(:(gamma(x)), :x)
catch err
    err
end
    GruntzError("unsupported function/operator `gamma` with 1 argument(s)")

    When there is no limit#

    A GruntzError is also thrown when the limit does not exist. For example, bounded oscillation:

    try
    gruntz_limit(sin(x), x)
catch err
    err
end
    GruntzError("argument of exp/sin/cos diverges (oscillation or essential singularity)")

    or one-sided limits that disagree, with dir = :both:

    try
    gruntz_limit(x/abs(x), x, 0; dir = :both)
catch err
    err
end
    GruntzError("one-sided limits differ")
